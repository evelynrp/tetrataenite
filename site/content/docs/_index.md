tetrataenite is a desktop operating system built on [Fedora Atomic](https://fedoraproject.org/atomic-desktops/). It's designed to be secure out of the box and to need as little maintenance as possible: the system, your apps, and your command-line tools all keep themselves up to date.

These docs cover how to install tetrataenite, how it behaves once it's running, and the handful of optional extras you can turn on.

## Who is this for?

tetrataenite is tailored to its maintainer's own taste and wasn't designed with a general audience in mind. That said, if you want reasonable security and very little bloat without having to configure anything, you're welcome to use it. Feedback and pull requests are welcome on [GitHub](https://github.com/evelynrp/tetrataenite).
